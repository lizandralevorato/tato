Passo a passo

  1. Agende. Entre no site com o seu e-mail da empresa, escolha o dia e o horário. Funciona no celular e no computador.
  2. Faça o check-in.{% if politica.checkin_prazo_min %} No dia, o check-in abre {{ checkin_abre }} antes da massagem e vai até {{ checkin_prazo }} antes. Você recebe um lembrete no celular com os botões Fazer check-in e Não vou.{% else %} Não é preciso confirmar antes; basta ir no horário.{% endif %}
  3. Avise que chegou. Na porta da sala, toque em Cheguei. O massoterapeuta recebe o aviso na hora.
  4. Não vai mais? Cancele até {{ politica.antecedencia_cancelamento_min }} minutos antes, para outra pessoa usar o horário.

Regras

  • Até {{ politica.max_por_semana }} massage{{ politica.max_por_semana|pluralize:"m,ns" }} por semana{% if politica.uma_por_dia %}, em dias diferentes{% endif %}.
  • Você pode agendar com até {{ politica.dias_para_agendar }} dias de antecedência.
    • {% if politica.checkin_prazo_min %}
  • Sem check-in até {{ checkin_prazo }} antes (com {{ politica.checkin_tolerancia_min }} minutos de tolerância), a reserva é liberada para outra pessoa.
    • {% endif %}
  • Tolerância de atraso: {{ politica.tolerancia_min }} minutos. Depois disso, o massoterapeuta pode marcar falta.
    • {% if politica.falta_conta_no_limite %}
  • Falta conta no limite da semana. Cancelamento feito no prazo não conta.
    • {% endif %}
  • Dia lotado? Entre na lista de espera e receba um aviso se alguém cancelar.

Feito para todas as pessoas

O site funciona com leitores de tela (TalkBack, VoiceOver e NVDA), com letras grandes, cores de alto contraste, avisos falados e tradução para Libras. Ajuste tudo em Preferências depois de entrar. Saiba mais sobre a acessibilidade do site.
